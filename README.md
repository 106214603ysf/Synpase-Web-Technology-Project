# Synapse Digital Health - Careers Website

Static recruitment website for **Synapse Digital Health** (industry G01: Digital Health & Wellness Provider).
Built for COS10026 Web Technology Project, Applied Web Project - Part 1 (Study Period 3, 2026).

## Accessibility and inclusion
Semantic HTML, skip link, `aria-current` navigation, alt text on all images, labelled form fields, visible keyboard focus,
responsive layout, and an Acknowledgement of Country with an inclusion statement for Aboriginal and Torres Strait Islander peoples.
